## 需求描述

现在要从多个 `Semaphore` 上取许可时，只能由调用方自己保证
**加锁顺序一致**，否则两个线程交叉持有就可能死锁。

希望库提供一个「加锁集」抽象：一次性声明本次要用到的多个信号量，
由库内部按固定顺序（例如按 `limit` 或按 key）统一加锁 / 释放。

## 期望用法

```python
from lockkit import LockSet

with LockSet(sem_a, sem_b, sem_c):
    ...          # 三个许可要么全拿到，要么一个都不拿
```

希望具备：

- 一次声明多个信号量，内部按稳定顺序加锁，从根上消除死锁
- 拿不到其中任意一个时，把已经拿到的全部回滚释放
- `LockSet` 自身可作为上下文管理器，退出时按相反顺序释放
