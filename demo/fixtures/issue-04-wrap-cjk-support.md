## 需求背景

`wrap()` 目前用空格分词，所以对**中文/日文/韩文**这类没有空格的文本完全不起作用：
整段中文会被当成一个"词"，原样返回一行超长文本。

## 现状

```python
from textkit import wrap

print(wrap("这是一段比较长的中文文本需要折行显示", 10))
```

**实际输出**

```
['这是一段比较长的中文文本需要折行显示']
```

**期望输出**（按显示宽度 10 列折行，即每行 5 个汉字）

```
['这是一段比较', '长的中文文本', '需要折行显示']
```

## 期望能力

1. **CJK 无空格文本**：按**显示宽度**折行，而不是按空格分词。
2. **中英混排**：英文单词不被拆断，中文按宽度切分。
   ```python
   wrap("Hello 世界 World", 10)
   # 期望：['Hello 世界', 'World'] 之类，英文单词完整
   ```
3. **全角字符按 2 列计**：全角标点、汉字、全角字母都算 2 列（East Asian Width）。
4. **兼容现有行为**：纯 ASCII 输入的折行结果不应改变，避免破坏既有调用方。

## 实现提示

- Python 标准库 `unicodedata.east_asian_width()` 可判断 `W`/`F`/`A` 类别为宽字符
- 也可用 `uniseg` 或 `wcwidth` 之类的第三方库，但需评估新增依赖
- 建议新增参数而非改变默认行为，例如：
  ```python
  wrap(text, width, *, east_asian=False)  # 或 auto=True 自动探测
  ```
- 需与 issue #3 的"统一文本口径"讨论联动：显示宽度是否属于库的核心语义
