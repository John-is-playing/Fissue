新增主机

只提交这一次：服务端立刻加密入库，任何接口都不会再回显它（连密文都不回）。 同名再次提交视为覆盖，必须重新给凭据——不做「留空则沿用」的隐式行为。

部署

提交后立刻返回「已受理」：一次部署可能跑几分钟，请求不会等它跑完。 进度与结果在「部署记录」里看（状态会从 planning → running → success/failed）。 计划仍会再校验一次，危险动作即使勾了也有「绝对拒绝」清单兜住。

回滚

回滚不复用原计划的步骤：它是一段固定动作（把 current 指回 previous → 重启 → 重新跑健康探针）， 走同一条 SSH 通道与同一套证据判定。几十秒级，会同步等到结果。回滚本身失败不会被伪装成 前一次部署的问题。

下线

下线 = 停掉服务 + 删掉这次部署的 release 目录，shared/（.env、上传目录、数据库文件） 保留——数据不该因为一次下线而消失。这个动作不可撤销。
