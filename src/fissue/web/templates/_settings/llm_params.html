计费与预算

输入单价
美元 / 1K 输入 token（llm.pricing.input_per_1k）
输出单价
美元 / 1K 输出 token（llm.pricing.output_per_1k）
日 token 上限
每仓库每日累计（llm.budget.daily_tokens_per_repo）；0 = 不限
日花费上限
美元 / 仓库 / 日（llm.budget.daily_usd_per_repo）；0 = 不限
超限即停
关掉 = 超预算只告警、不中断调用（告警会出现在「状态监测」页）。

生成参数

temperature
0~2（llm.temperature）
单次上限
max_tokens；推理模型的 reasoning 会吃掉大半预算，别调太小
截断加码上限
max_tokens_ceiling（被长度截断时翻倍重试，但不越过它）
并发
同时在跑的 LLM 请求数（llm.concurrency）
大模型超时
秒（llm.timeout_seconds）
重试次数
次（llm.max_retries）
