关掉它**不等于**「谁都能进」：那时只靠下面的可信网段与本机回环放行，其它来源一律被拒。 没有管理员账号时，请到 /login 用引导口令完成初始化。
可信内网
每行一个 CIDR（web.trusted_networks）。落在这些网段里的来源 视为等同回环（免登录、可写配置）——这是「内网直接用浏览器访问」的正路。 判定只看真实对端地址，不信任 X-Forwarded-For； 挂在反向代理后面时请把代理所在网段写进来。要单机就写 /32，别写裸地址。
会话时长
分钟（web.auth.session_ttl_minutes）。过期即需重新登录。
安全 cookie
反向代理已提供 HTTPS 时才打开。纯 HTTP 下打开它，浏览器会直接丢弃会话 cookie——表现是「登录了，但下一步又要求登录」。
失败上限
连续失败多少次后开始指数退避锁定（web.auth.login_max_failures）。

远程改配置
默认关闭：只有本机回环（或已开鉴权并带对口令）才能改配置。打开它 = 本机以外也能改密钥， 仅建议在完全可信的内网里自用。
改完记得点上方的「保存设置」——这里不放第二个按钮，免得你以为 这一页有「各自保存」。 密钥留空 = 不改动；勾「清空」= 移除**本层**的设置 （若 config.yaml 里也写同一个键，它会接着生效——「来源」列表里看得到谁在生效）。
